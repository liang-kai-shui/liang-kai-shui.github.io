源码丢了又找回来了：本站近期折腾记录

发表于2026-09-09|更新于2026-09-10|折腾记录
|总字数:1.6k|阅读时长:5分钟|浏览量:

生活明朗，万物可爱。

好久没写新东西了。这两个月没更新文章，倒是把整个小窝从里到外翻修了一遍 —— 起因挺离谱的：源码丢了。

一、事故现场

某天想改点东西，打开 GitHub 仓库一看，人有点懵：

仓库里躺着 34 次提交，全都叫 Site updated: xxxx-xx-xx，一个字的源码都没有。

原因其实特别常见：hexo-deployer-git 推上去的永远是 public/ 里的构建产物，源码从来只活在本地。本地那份一丢，就真没了。

当时摆在面前的三条路：

方案 可行性
从 GitHub 找回源码 ✗ 仓库里只有产物，也没有第二个分支
从本机 / 回收站找回 ✗ 全盘搜过一遍，没有 _config.yml，也没有 themes/
从构建产物反向重建 ✓ 可行，而且能做得几乎一模一样

二、重建是怎么做的

好在 Hexo 的产物信息量很大，相当于把答案抄在了卷子上：

<meta name="generator"> 直接给出 Hexo 版本；主题的 js/main.js 哈希能定位主题版本；
编译后的 css/index.css 里，所有配置项生效后的结果都看得见。

大致的流程是：

  1. 克隆线上仓库，把 90 个产物文件全部拆开看一遍
  2. 拿 js/main.js 的 SHA256 去比对主题的每一个 tag，锁定到 Butterfly 5.3.3
  3. 从编译后的 CSS 反推配置（配色、字号、代码块主题、加载动画……）
  4. 按 5.3.3 装好主题、把配置写回去，然后逐文件 diff，差什么补什么

后来翻云盘，还翻出一份 2025 年 2 月的源码备份，里面有真实的 _config.yml、package.json 和 package-lock.json。插件版本一按 lock 锁死，产物立刻就对上了。

看一眼还原度校验的结果

剩下的差异来自构建时间戳、页脚年份、域名，以及后来故意改掉的东西（新文章、新脚本）。这个校验脚本留在仓库里了，npm run verify 随时能跑。

三、顺手修好的一堆东西

重建完才发现，原来有些东西早就坏了，只是一直没人注意：

问题 真正的原因 状态
音乐播放器不见了 MetingJS 的默认接口已经挂了 已修复
侧边栏电子钟一片空白 天气 key 后面跟着注释、API Host 没配 已修复
电子钟永远显示长沙 高德 IP 定位只认 IPv4，而浏览器走的是 IPv6 已修复
加载动画只有个空圆框 头像图片路径写错了，一直 404 已修复

一个一个说。

🎵 音乐播放器

播放器是靠 APlayer + MetingJS 取网易云歌单的，而 MetingJS 默认调用的
api.i-meto.com 这个接口已经失效了。取不到歌单，APlayer 干脆整个不渲染 —— 表现就是”播放器凭空消失”。

换成可用接口后就好了：

这类公共接口都不太稳定，挂了就换一个。想要一劳永逸，可以自己部署一份 Meting API 到 Cloudflare Workers 或 Vercel。

⏰ 电子钟：从”一片空白”到”显示错城市”

电子钟的渲染逻辑是先取天气、再画时钟 —— 天气接口一失败，整张卡片就是空白，看着像时钟坏了。

原配置里踩了两个坑：

  • qweather_key 后面跟了一串注释（# 和风天气key），被一起拼进了请求 URL；
  • 没配 qweather_api_host，于是回退到插件作者自己的域名，而那个域名只认作者本人的 key。

两个都会拿到 403 Invalid Host。清理之后又发现新问题：永远显示长沙。

查下来是个很隐蔽的坑：

高德的 IP 定位接口明确写着「仅支持 IPV4，不支持国外 IP 解析」，而 restapi.amap.com
同时有 IPv6 地址。访客浏览器优先走 IPv6 去请求，高德就直接返回空数组。

同一台机器实测：

所以现在的做法是：先取访客的 IPv4，再带 ?ip= 参数调高德，后面还有两层兜底。切走再回来，Console 里能看到这样一行：

🖼️ 加载动画

打开网页时中间那个圆形头像，其实一直是空的 —— loading.css 里图片路径写成了 /source/img/p18.webp，
这个路径不存在（404），而图片真正的家在 /img/p18.webp。改一个字符就好了。

四、新增的小彩蛋

标签页标题

现在切走标签页，标题会变成：

这就要走了吗 (｡•́︿•̀｡)

而且每 4 秒换一句（不会连续重复）。切回来的瞬间是：

你终于回来了 (ﾉ´ヮ`)ﾉ*: ･ﾟ

3 秒后自动恢复成正常的站点标题。

首页布局

以前打开首页是整屏底图，一篇文章都看不见。现在头图只占半屏，下半屏直接就是文章列表：

六、写在最后

折腾这一圈最大的感受是：构建产物也是源码。只要产物还在，很多东西都能反推回来 —— 当然，还是别赌这个，源码记得多存一份。

顺便说一句，现在这篇是重建之后的第一篇文章，能正常发出来，说明这条流水线是通的 🎉
