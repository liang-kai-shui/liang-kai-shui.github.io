## 站点说明

博客基于 [Hexo](https://hexo.io/) 搭建，使用 [Butterfly](https://github.com/jerryc127/hexo-theme-butterfly) 主题。

本仓库中保存的是 Hexo 构建生成的**静态站点文件**（HTML、CSS、JS、图片等），并非可再次构建的项目源文件。

## ⚠️ 重要说明

由于本博客的**项目源文件已经遗失**，本仓库仅保留构建后的静态文件，**博客后续不会再进行更新**。
